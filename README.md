Java 17 буюу түүнээс дээш хувилбар, JUnit 5, Mockito 5 ашиглана.

## Ажиллуулах

Linux болон macOS:

```sh
./mvnw test
```

Windows PowerShell дээр энэ компьютерт суусан JDK-г ашиглах:

```powershell
$env:JAVA_HOME = 'C:\Program Files\Android\openjdk\jdk-21.0.8'
.\mvnw.cmd test
```
